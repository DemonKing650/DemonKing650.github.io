New Survivor Onboarding

Join ZoD Varynth

Follow these steps to find the crossplay cluster and begin your progression.

Step 1 of 5

Install ARK: Survival Ascended

Launch ARK: Survival Ascended from Steam, the Microsoft Store, or the Xbox app.

Crossplay Supported

The ZoD Varynth cluster accepts supported PC, Xbox, and PlayStation survivors.

Step 2 of 5

Open the server browser

From the main menu, choose Join Game, then open the Unofficial server list.

1 Select Join Game 2 Choose Unofficial 3 Allow the list to finish loading
Step 3 of 5

Search for the cluster

Enter the short cluster name below. Searching only the short name is usually easier than typing the entire server title.

Search Term ZoD Varynth
Step 4 of 5

Choose your map

Select the map where you want to begin. Both maps belong to the same PvE cluster and support transfers.

Recommended Start The Center Explore the established cluster map. Cluster Map Lost Colony Continue your adventure across the network.
Step 5 of 5

Download mods and survive

Select the server and allow ARK to download any required crossplay mods. After installation, reconnect if the game asks you to restart.
